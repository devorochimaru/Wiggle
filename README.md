Make sure you've allowed the file to run in your browser. Sometimes, security settings can block new applications. If you see a warning, look for an option that says "Run Anyway" or "Allow."

Your browser might question the download because Wiggle is a new, lesser-known application. This is normal safety behavior. Just confirm that you want to download the file from GitHub, and you'll be good to go.
